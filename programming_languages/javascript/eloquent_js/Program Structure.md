# Expressions and Statements
- A fragment of code that produces a value is called an _expression_. Every value that is written literally (such as 22 or "hello world!") is called an expression.
- A statement corresponds to a full sentence. The simplest kind of statement is an expression followed by a semicolon.
```js
!false;
```

- A _side effect_ occurs when a statement changes something in the state of the machine or when a value is displayed on the screen.

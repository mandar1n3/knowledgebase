# Network basics: Course Introduction

The goal is to be equipped with the vocabulary necessary for communicating
effectively with the network administrator(s) and be able to recognize issues
and explain them using the learned vocabulary.

- DNS can be thought as an address book for servers.
- A network is a way to connect multiple operators with each other
  to enable communication between the operators.

- Each connected device in a network has its own unique number and are 
  connected to a switch.
- Phone and computers can be called ETTD. Connexion devices are called ETCD.

- Media: there are different types of ways information can be exchanged: 
    - Wifi
    - Bluetooth
    - Ethernet cable

- Somme communicaation devices are:
    - Hub (concentrateur), !!! Collisitions can occure.
    - Switch (commutateur). When communicating the connected divices are _linked_
      togethere allowing to avoid collisitions speeding up data transfers.
    - Wireless Access Points.

- Some terminal devices:
    - Router
    - Computer
    - modem-router
     - switch
     - router
     ...

- LAN, a collection of devices connected to a switch.
    - each lan has its ip address.
    - we can connect multiple lans with a router.

- The gateway allows us to leave a local network to reach the _outside_. 
  its a doorway to the _outside_.

- IPv4 Adress: IP adress and __subnet mask__:
 - A number based on 32 bits that offers 4billion possible addresses.
 - Limits the number of unique identifiers for connected devices.
 - Presented by four numbers (rangeing from 0-255) seperated by dots.
- A solution was to create private and public address and then switched to
  IPv6.
- An IP address is only usefull if we have its subnet mask.

- The NAT job is to translate an private address to a public address and 
  vice versa. It takes places in the router-modem.
